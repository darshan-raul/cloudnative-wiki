## Learning and example gaps

- SQS and SAP FIFO language should distinguish deduplication, ordered groups and processing idempotency; a visibility timeout can cause redelivery even though FIFO avoids duplicate enqueue during its deduplication interval. Do not teach a business-level exactly-once guarantee without the failure model.
- SQS pricing scenarios count only send traffic, omit receive/delete, empty polls and request-size metering. The claimed FIFO batching discount ($0.017/million) needs verification; batching reduces request count, not an invented request tariff.
- EventBridge examples need target IAM/resource policies, a complete event payload, delivery-failure retry/DLQ setup, archive replay safety and idempotency. Add Scheduler/Pipes rather than presenting legacy scheduled rules as the whole platform.
- Step Functions ASL fragments need explicit fragment labels and one complete deploy/test/cleanup workflow. Explain Retry/Catch, execution identity, timeout, history/logging, payload limits and external-side-effect duplication. Express pricing must include memory-duration rather than generic execution-minutes.
- AppSync needs complete resolver/data-source/IAM setup, AppSync JavaScript versus VTL, mutation selection-set/subscription coupling, authorization testing, connection lifecycle and GraphQL versus Event API ownership.
- Amazon MQ needs a deployment lab with supported broker version/protocol/plugin combinations, VPC access, failover testing and client recovery. Its long quota/pricing tables are not directly sourced.
- The integration hub says the default EventBridge bus only accepts AWS events, while its own EventBridge tutorial publishes custom events to that bus: reconcile the contradiction.
