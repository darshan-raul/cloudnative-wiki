# Amazon Data Lifecycle Manager

"https://docs.aws.amazon.com/ebs/latest/userguide/snapshot-lifecycle.html"

This is a tool exclusively for managing the backup lifecycle of ebs volumes. taking regular amis and rotating old backups plus can also do cross account and cross region copy.
